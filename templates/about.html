About DR Predict

An AI-powered diabetic retinopathy detection system built with Python, TensorFlow, and modern web technologies.

🎯

Objective

To provide an accessible, AI-driven tool for early detection of diabetic retinopathy from retinal fundus photographs, enabling timely medical intervention.

🧠

Technology

Built using a MobileNetV2-based Convolutional Neural Network trained on the APTOS 2019 dataset with transfer learning and fine-tuning.

📊

Performance

Achieves strong classification accuracy across 5 DR severity stages using image augmentation, CLAHE preprocessing, and optimized training pipelines.

🔒

Data Privacy

All patient data is stored locally in a SQLite database. No data is transmitted externally. Reports are generated offline.

Technology Stack

🐍Python 3.10+
🧪TensorFlow / Keras
📐Scikit-learn
🐼Pandas
🔢NumPy
👁OpenCV
🗄SQLite3
📈Matplotlib
🌐Flask
📄ReportLab

⚠ Medical Disclaimer

This system is intended for research and educational purposes only. It is NOT a certified medical device and should NOT be used as the sole basis for clinical decisions. Always consult a qualified ophthalmologist or healthcare professional for proper diagnosis and treatment.
